# Klypa

Gestor de portapapeles para Windows. Guarda textos, imagenes, enlaces y archivos en una franja que puedes abrir con un atajo, buscar por tipo y reutilizar al instante.

[Descargar Klypa para Windows x64](https://github.com/network961/klypa-updates/releases/download/klypa-latest/Klypa-latest-x64-setup.exe) · [Version y novedades](https://github.com/network961/klypa-updates/releases/latest)

## Funciones

- Historial local con filtros, busqueda, favoritos y seleccion multiple.
- Copiar, pegar o copiar y pegar con un comportamiento configurable.
- Desplazamiento con la rueda y las flechas del teclado.
- Editor de imagenes con recorte, dibujo, rotacion y volteo.
- Editor de texto con correccion ortografica y exportacion a TXT.
- Temas claro, oscuro y del sistema, con color de marca personalizable.
- Conservacion configurable del historial; los favoritos quedan protegidos del borrado automatico.
- Actualizaciones integradas desde Configuracion > Actualizaciones.

## Descargar y actualizar

Descarga el instalador `.exe` del enlace oficial. Si ya tienes Klypa, abre Configuracion > Actualizaciones y pulsa Buscar actualizaciones. Desde esa pantalla tambien puedes compartir el enlace de descarga.

Los paquetes del actualizador incluyen una firma que Klypa comprueba antes de instalarlos.

Este repositorio distribuye las descargas y novedades de Klypa. El codigo fuente de la aplicacion no se publica aqui.
